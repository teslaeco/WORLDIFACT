# STANDARD context presentation repair

Local implementation only. No installation, service restart, provider call,
replacement job, ledger mutation or customer charge is performed by this package.

The existing STANDARD route prints its entire modeling contract into model
history, including repeated original instructions and geometry guidance. Every
subsequent request also receives a long repeated execution/completion guide.
That context is counted again before each model request under the existing cap.

This package changes only the explicit STANDARD initial task and turn guidance.
It supplies the complete losslessly factored scene schema (all 18 primitive
variants and all subject types), original geometry guide, ordered reference
mapping, original prompt and original execution instructions upfront. The first
exec stores the unchanged complete MCP contract and builds the complete scene,
without printing that whole contract. Later access selects the needed fields
from Code Mode store or documented revision/SHA-bound current-model pages.

Required inspection images and current summary can share the existing single
inspection exec. A later model turn must actually assess those pixels before
editing or finishing. Current-revision render and finish gates are unchanged.
This does not claim that any observed job had redundant render calls.

Cabinet, reference-character, FAST and unmarked Froge task/guidance behavior is
unchanged. The original MCP, renderer validator, spend policy, settlement,
completion/continuation rules, images, security and limits are unchanged.
Display `$defs` references never enter the generated scene or canonical validator.

## Verification

Eight synthetic tests check exact installed-prebuild ancestry; unchanged source
outside task/guidance routing; all schema variants and photo constraints for
0/1/3/4 references; preservation of original Unicode instructions and reference
order; untouched other routes; current-revision/error guidance; the actual
adapter's STANDARD input; and one-exec store/build sequencing with inert tool
doubles followed by the unchanged real scene parser.

For the fixed synthetic zero-photo dragon brief, measured build-request text
components fall from 54,100 to 39,157 Unicode characters (27.6%). This excludes
CLI catalogs, actual wire encoding, generated code, images and later turns.
It is not actual tokenizer, invoice, real-model quality or success evidence.

Local validation also passed the existing 148 completion and 45 prebuild tests,
874 non-browser JavaScript tests, lint (existing warnings), TypeScript, production
build, real local DEMO HTTP smoke and Worker deployment dry-run. The known-blocked
native Chromium regression was not retried, so the full `npm run verify`
aggregate remains incomplete. Independent read-only review found no blocking
issue and reproduced the eight new tests and text-size measurement. Actual
CLI/MCP/Blender execution and hosted CI were not run for this package.

Run from the repository with the original pinned public Froge source:

```sh
MODEL_COMPLETION_SOURCE=/path/to/pinned/oracle_connector \
  python3 -B -m unittest discover -s tools/model_context -p 'test_*.py' -v
```

For an already reconstructed reviewed prebuild ancestor, use
`MODEL_CONTEXT_ANCESTOR=/path/to/prebuild-ancestor` instead. Both paths reconstruct
the current prebuild bytes before validating the immutable before-state hashes.

## Deployment remains blocked

`context_patch.changes` returns proposed bytes in memory only. This package has
no installer or launcher and must not be applied by the existing maintenance
helper. Existing receipts do not include the new helper. Installation requires
a separately reviewed, race-safe service stop/quiescence mechanism, new verified
receipt coverage including `context_policy.py`, rollback checks and genuine
offline CLI/MCP/Blender verification before advertising readiness. No readiness,
live success, fidelity or deployment claim is made here.
