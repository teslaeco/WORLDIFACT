## Exact model artifacts (generated, not deployed)

An original parametric green/blue humanoid mechatronic robot with a large physical green chili. One side uses layered metal/painted armour; the other exposes electrical MCC-style terminals, motor assemblies, copper coils, cylindrical mechanisms, joints and luminous blue/green LED material parts. An image reference is concept art, not an asset generated by the underlying 3D pipeline.

The original **GAME** artifact has 959 independent editable named meshes, 64,376 actual triangles, 14 base PBR material definitions, 1,343,672 bytes, SHA-256 `6b5edf630855668afb6e7cb93093d5770b0252c36b2ab2c0d08d47ba2018b471`. It is a real, colored GLB 2.0, but has **no rig/animation and no authored external UV texture maps**.

The separate fine **MAKE** candidate has 196,542 surface triangles, one watertight, consistently wound volume, bounds **118.48 × 78.23 × 180.00 mm**, 9,827,184 bytes, SHA-256 `5750b7055279fd35aec6d75bc113bdfcadf7759c7093fb71c813ebd13dce8ce1`. It was derived using solid voxel union and thickening, so some fine geometry is deliberately simplified; it is a **monochrome SLA printing study only**. Neither wall-thickness coverage, support removal, shell drainage, surface finish nor physical fit has been confirmed by a supplier. Never market it as print-ready.

**Truthful provenance**: the geometry was created offline with Python trimesh in the operator's isolated validation environment, **not** GPT-6 Astra, Sol, Luna, Tripo or Meshy. No AI API call, no customer points, no supplier order, no payment. The original binary files and self-contained interactive HTML/QA reports have been delivered to the owner as a separate portable preproduction package; they are not yet hosted within the deployed WORLDIFACT production CDN or committed as binary to this GitHub branch. **Do not construct public download URLs from these filenames until object storage/asset hosting is actually implemented and verified.** This registry is deliberately *metadata only*, not a false "model already in library" record.

## Recovered actual B2B correspondence

The owner contacted Sculpteo, JLC3DP, TRIDEO, Objective3D and PROFORM AG on 13 Sep 2026 about manufacturing detailed figures and scale models, colors, global fulfilment, quality control and per-kg-vs-per-model pricing. This pilot reuses only verified replies:

**Sculpteo (14–15 Sep 2026):** uploaded STL/OBJ/STEP, select actual material/finish to receive a quote, order a single sample before volume production; prices vary with envelope/part volume, machine utilisation and finishing, not a blanket per-kg rate. Their team referred API access questions to an actual technical contact. No B2B API order automation approval, invoice terms, authenticated sandbox or white-label shipping has been verified for WORLDIFACT.

**JLC3DP (14 Sep 2026):** monochrome STL recommended; STP/STEP/OBJ also supported. Full-colour WJP supports OBJ+MTL+PNG (4K textures recommended, packed), 3MF, or PLY; **100 MB file limit**. Quotation is per model, engineer review before payment is supported, not a fixed per-kg manufacturing tariff. The supplier did not approve this actual robot geometry for production.

Current official JLC3DP material guidance (checked 14 Oct 2026):
- [General printing guidelines](https://jlc3dp.com/help/article/3d-printing-design-guideline): near 200 mm resin SLA size, recommended thickness around 2.0 mm, minimum simple assembled clearance 0.2 mm, moving parts 0.5 mm, nominal tolerance above 100 mm ±0.3% for SLA; real results depend on model/material/finish.
- [WJP full-colour](https://jlc3dp.com/help/article/wjp-products-design-guidelines): around 200 mm minimum wall ~3 mm; hollow parts are not supported. **This prototype is NOT WJP-approved.**
