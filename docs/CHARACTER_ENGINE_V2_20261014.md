## Actual code changes

- `src/lib/studioProtocol.ts`: text-only anatomically explicit requests select `text-character-detail-v2`; explicit combat/humanoid robots select `articulated-robot-detail-v2`. Generic models and historic photo character/MCC payloads are preserved. Prompt preparation still uses supported `tools.mcp__blender__` contracts, first-build completeness, multi-view inspection, checked `finish_model` and the original provider cap. An unsupported rig or 3D detail cannot be claimed.
- `src/lib/studioMeshEvidence.ts`: independent bounded checks of embedded GLB BIN, accessor ranges, position float finiteness and physical nondegenerate triangle samples. The geometric summary does **not** prove aesthetic fidelity or topology. Invalid or incomplete original artifacts remain invalid.
- `src/lib/studioQuality.ts`: prospective objective character/robot minimum triangles, source-part and material thresholds. Never artificially subdivide hidden/duplicate geometry to meet counts.
- `server/studio.ts`: strict V2 candidate rejection is deliberately OFF by default until the same original GLB can be retained and downloaded even after quality failure. No new API or currency debit is introduced. No changes to Astra, Sol, Luna price ceilings or customer points.
- `src/components/StudioGallery.tsx`: report actual opened-file GLB-declared triangle, rendered instance, mesh and material counts with an explicit note that this is not a perceptual quality review. No extra provider request.

## Third-party Character Engine: reviewed but NOT enabled

A specialized image-to-3D/text-to-3D model is a **RECOMMENDATION**, not currently WORLDIFACT production.

Official API evidence checked 14 October 2026:

- Tripo H3/H2 text-to-model with texture: **20 credits = USD 0.20**; image-to-model with texture: **30 credits = USD 0.30**. H3 high-detail options may increase those costs. Conversion, retopology, segmentation, rigging and other add-ons are additional billable tasks. See https://docs.tripo3d.ai/get-started/pricing.html and https://developers.tripo3d.ai/.
- Tripo authenticates using server-only Bearer tokens and uses `POST /v2/openapi/task`, read task status by `GET /v2/openapi/task/{task_id}`. Source: https://docs.tripo3d.ai/get-started/quick-start.html.
- Meshy image-to-3D with 2K/4K texture: **30 API credits**; full Text-to-3D preview mesh and refinement is **20 + 10 API credits** on current Meshy models. Credit-to-dollar conversion is not universally the Tripo conversion and depends on purchases. https://docs.meshy.ai/en/api/pricing.
- An eventual hybrid output must disclose two provenance fields independently: **AI Director** (actual, confirmed Astra/Sol/Luna response), **Geometry Provider** (actual, confirmed Blender/MCP, Tripo or Meshy task), plus original task IDs, price/cost receipts and GLB SHA-256. Do not label a Tripo-generated mesh as purely "Generated by Astra". No provider key belongs in the frontend.

Security architecture required before any external provider task:
1. Server-only API key, explicit paid user authorization and capped credit reservation BEFORE a single immutable external task is submitted.
2. A durable job ID and idempotent submission fence, persistent async polling across browser refresh, rate limits, timeouts and safe error mapping. No automatic provider retry.
3. Verified account ownership, task provenance and saved GLB bytes (not only task URL). Validate actual geometry and hash, then show exact statuses and point settlement; provider credits and customer points are separate quantities.
4. Separate execution routes for mechanical engineering and organic characters; selectable or appropriately disclosed hybrid provider, with user approval before sending images to a third party.
5. Controlled same-reference comparisons with at least 3 subject categories, recorded true cost and time, not vendor-selected marketing images.

## Explicit disclaimer

This PR materially improves generation instructions and truthful geometry measurement. It does **not** yet demonstrate Tripo-level postprocessing, high-poly results or a verified production Character Engine. Synthetic test meshes do not represent high-quality character art. The competition is decided by actual audited original GLB output, not software feature labels.
